📖 Cómo usar el panel

1️⃣ Cómo registrar un pedido Entra a 🛍️ Pedidos → escribe el nombre del cliente, detalle, fecha y hora → toca + en los productos que quieras agregar → verifica el total → toca Guardar pedido.
2️⃣ Cómo crear una reserva Entra a 📅 Reservas → llena datos del cliente, fecha, hora, mesas y sillas → agrega productos → revisa el adelanto (50%) que se calcula solo → toca Guardar reserva.
3️⃣ Cómo imprimir o descargar el PDF En cualquier pedido o reserva ya guardada verás dos botones: 📄 PDF (descarga el archivo) y 📤 Compartir (lo envía por WhatsApp, Gmail, etc.).
4️⃣ Cómo usar la calculadora Entra a 🧮 Calculadora → toca los números y operadores → = para ver el resultado → Limpiar para empezar de cero.
5️⃣ Cómo activar el sonido de fogata Toca el engranaje ⚙️ arriba a la derecha → activa Sonido de fogata. También puedes cambiar el tema de colores y los efectos 3D desde ahí.
6️⃣ Cómo administrar la página principal Entra a 🎨 Página principal → abre GitHub o Vercel con tu cuenta autorizada para editar el contenido.
